# EDE Anti-Patterns

## Plausibility Collapse
A plausible explanation is silently upgraded to fact.

## First-Hypothesis Anchoring
The first explanation determines what evidence the agent searches for.

## Confirmation-Only Search
Contradictory evidence is ignored or underweighted.

## Legacy Arrogance
Strange code is assumed to be incompetent code.

## Refactor Opportunism
A local bug becomes an excuse for unrelated architecture changes.

## Compile Equals Correct
A passing build is presented as proof of behavioral correctness.

## False Precision
The agent invents confidence values such as 87% without a measurement model.

## Process Theater
The agent produces large investigation templates for trivial edits.
